Brisa Suave OS: repositório de atualizações

Daqui o Brisa Suave Update baixa as novidades do Brisa Suave Central, Update, Store e dos temas. Quem usa o Brisa Suave OS não precisa fazer nada: já vem configurado.

Versão atual dos apps: 1.0.0

Para adicionar à mão num Debian:

sudo curl -fsSL -o /usr/share/keyrings/brisa.gpg https://gabgolgamer44-a11y.github.io/brisa-suave-os/brisa.gpg
echo "deb [signed-by=/usr/share/keyrings/brisa.gpg] https://gabgolgamer44-a11y.github.io/brisa-suave-os estavel main" | sudo tee /etc/apt/sources.list.d/brisa.list
